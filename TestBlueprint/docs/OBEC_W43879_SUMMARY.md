# สรุปหนังสือ สพฐ. ที่ ศธ 04004/ว43879 ลงวันที่ 5 กันยายน 2568

เรื่อง: แนวปฏิบัติเพื่อให้การดำเนินงานเกี่ยวกับการใช้ข้อสอบแบบเขียนตอบในการวัดและประเมินคุณภาพผู้เรียน
ลงนาม: นางเกศทิพย์ ศุภวานิช รองเลขาธิการ กพฐ. ปฏิบัติราชการแทนเลขาธิการ กพฐ. · ผู้รับผิดชอบ: สำนักทดสอบทางการศึกษา
แหล่งที่อ่าน: ไฟล์สแกน 2 หน้า จาก kroobannok.com/92929 (อ่านจากภาพโดย Claude 13 พ.ย. 2569 — ควรเทียบกับหนังสือฉบับที่โรงเรียนได้รับ)

## ที่มา (อ้างถึง)
- ประกาศ สพฐ. 18 เม.ย. 2557 ข้อ 7: ข้อสอบเขียนตอบ "อย่างน้อยร้อยละ 30 ของการสอบแต่ละครั้ง"
- ประกาศ สพฐ. 9 ม.ค. 2563 (มีผลตั้งแต่ปีการศึกษา 2562): แนวปฏิบัติการใช้ข้อสอบแบบเขียนตอบ

## ข้อกำหนดระดับสถานศึกษา (ข้อ 2) — ทั้งหมดที่หนังสือระบุ
| ข้อ | สาระ |
|---|---|
| 2.1 | **กำหนดแผนผังการออกข้อสอบ (Test Blueprint)** สำหรับ สอบท้ายหน่วย, สอบระหว่างภาค, สอบปลายภาค · มีทั้งแบบเลือกตอบและเขียนตอบ **"อย่างน้อยในสัดส่วนคะแนนร้อยละ 50 : 50 ของคะแนนเต็มในการสอบแต่ละครั้ง"** |
| 2.2 | ใช้ข้อสอบเขียนตอบ **ทุกกลุ่มสาระ** ทั้งแบบจำกัดคำตอบและไม่จำกัดคำตอบ; มัธยมเน้นแบบไม่จำกัดคำตอบ |
| 2.3 | ข้อสอบเขียนตอบเน้นการคิดขั้นสูง มีสถานการณ์ให้คิดวิเคราะห์ สังเคราะห์ ตัดสินใจ สร้างสรรค์ |
| 2.4 | วิเคราะห์ผลการตอบข้อสอบเขียนตอบ **รายข้อ รายคน** เพื่อวินิจฉัยข้อบกพร่องและพัฒนาผู้เรียน |
| 2.5 | กำกับติดตามการใช้ข้อสอบเขียนตอบอย่างเคร่งครัด |
| 2.6 | ส่งเสริมให้ครูพัฒนาข้อสอบเขียนตอบ เก็บเป็น **คลังข้อสอบ** ให้บริการ |

## สิ่งที่หนังสือ **ไม่ได้** กำหนด
- ไม่มีแบบฟอร์ม Test Blueprint ที่บังคับ
- ไม่มีบันทึกขออนุมัติ / ลำดับการลงนาม
- ไม่ได้กำหนดให้ใช้ Bloom's Taxonomy (พูดถึง "การคิดขั้นสูง")
- ไม่ได้กำหนดให้วิเคราะห์ค่าความเชื่อมั่น/ความยาก/อำนาจจำแนก (กำหนดเฉพาะวิเคราะห์ผลเขียนตอบรายข้อรายคนเพื่อพัฒนาผู้เรียน)
- ไม่ได้กำหนดให้ทำ IOC

## ⚠️ จุดที่ขัดกับแบบฟอร์ม วผ.29 ของโรงเรียน
- วผ.29 เขียนว่า ปรนัย **ร้อยละ 70** / อัตนัย **ร้อยละ 30** — ตรงกับประกาศเก่าปี 2557 (≥30%)
- หนังสือ ว43879 (2568) กำหนด **อย่างน้อย 50 : 50** → ข้อสอบเขียนตอบต้อง ≥ 50% ของคะแนนเต็ม (ตีความตามถ้อยคำ — ควรยืนยันกับ สพม./สำนักทดสอบ)
- ผลต่อระบบ: เกณฑ์ใน validator ต้องเป็นค่าที่ตั้งได้ ไม่ฝังตายตัว
