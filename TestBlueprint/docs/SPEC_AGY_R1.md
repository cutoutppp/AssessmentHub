## 2. ข้อมูลรายวิชาที่ใช้ (จาก `COURSES_2_2569[code]`)

| ฟิลด์ | ใช้ทำอะไร |
|---|---|
| `course_code`, `course_name`, `grade_level`, `learning_area` | หัวเอกสาร |
| `units[].unit_no`, `units[].unit_name` | dropdown หน่วย |
| `units[].indicators` (มีแค่ ~69 วิชา) | ตัวชี้วัดของหน่วย (ถ้ามี) |
| `indicators` (ระดับรายวิชา) | ตัวชี้วัดทั้งหมดของวิชา — ใช้เมื่อหน่วยไม่มี |
| `midterm_cutoff` | หน่วยที่ 1..cutoff = ช่วงสอบกลางภาค; ที่เหลือ = ปลายภาค |
| `mid_exam`, `fin_exam` | คะแนนเต็มของการสอบ (ใช้ตรวจคะแนนรวม) |
| `is_scheduled_term2` | กรองรายวิชาภาคนี้ |

`js/courses.js` ต้องมี:
- `cleanIndicatorText(s)` — ลบช่องว่างแทรกระหว่างอักษรไทย (เช่น `แ ล ะ ค วาม` → `และความ`) โดยไม่รวมคำที่ตั้งใจเว้นวรรค: รวมเฉพาะลำดับที่เป็นอักษรไทยตัวเดียวคั่นด้วยช่องว่าง ≥2 ครั้งติดกัน; ยุบช่องว่างซ้ำ — **อ้างอิงแนวทาง** `cleanThaiText` ใน `assessment-plan/js/generator.js:163` (อ่านได้ ห้ามแก้)
- `parseIndicator(s)` → `{code, type: 'ระหว่างทาง'|'ปลายทาง'|null, text}` จากรูปแบบ `ค 1.1 ม.1/1 (ปลายทาง): ข้อความ`; รายวิชาเพิ่มเติม (ไม่มีรหัส) → `{code:null, text}` แสดงเป็น "ผลการเรียนรู้ข้อ n"
- `unitsInRange(course, examType)` — MID: หน่วย 1..`midterm_cutoff`; FINAL: หน่วยที่เหลือ; ถ้า `midterm_cutoff` ว่าง → แสดงทุกหน่วย + เตือน
- `indicatorsForUnit(course, unit)` — หน่วยมีตัวชี้วัด → ใช้ของหน่วย; ไม่มี → คืนตัวชี้วัดทั้งรายวิชา (ครูเลือกเอง)

## 3. โครงสร้างข้อมูล (draft ใน localStorage)

```jsonc
{
  "v": 1,
  "course_code": "ค21101",
  "exam_type": "MID",                 // MID | FINAL
  "term": "2", "year": "2569",
  "learning_area": "คณิตศาสตร์",       // แก้ได้
  "teacher_name": "",                 // ครูพิมพ์เอง (ไม่มี login)
  "objective": { "count": 20, "points_each": 1 },
  "subjective": { "count": 2, "points": [3, 3] },   // คะแนนรายข้อ; ความยาว = count
  "standard_text": "",                // บรรทัด "มาตรฐานการเรียนรู้/ผลการเรียนรู้" เหนือตาราง (ไม่บังคับ)
  "indicator_text": "",               // บรรทัด "ตัวชี้วัด" เหนือตาราง (ไม่บังคับ; ว่าง = ระบบสรุปรหัสจากตาราง)
  "rows": [
    {
      "unit_no": "1", "unit_name": "...",
      "indicator": "ค 1.1 ม.1/1 ...",   // ข้อความเต็มที่เลือก/พิมพ์
      "indicator_custom": false,
      "bloom": 2,                       // 1–6
      "obj_items": "1-5, 8",            // ข้อความดิบที่ครูพิมพ์
      "subj_items": "21"
    }
  ],
  "updated_at": "ISO"
}
```
- อัตนัยใช้ **เลขข้อต่อจากปรนัย** (ปรนัย 1–20 → อัตนัย 21, 22) — แสดงคำอธิบายนี้บนหน้าจอ
- คะแนนของแถว = (จำนวนปรนัยในแถว × points_each) + ผลรวม `subjective.points` ของข้ออัตนัยในแถว
- localStorage key: `wp29:<course_code>:<exam_type>`; ปุ่ม "ส่งออกไฟล์งาน (.json)" / "นำเข้า" สำหรับย้ายเครื่อง

`parseItemRange("1-5, 8,10–12")` → `[1,2,3,4,5,8,10,11,12]`; รับ `-` และ `–`, ช่องว่าง, คอมมา, เลขไทย ๐–๙; ข้อความผิดรูป → `{error}` (ไม่เดา)
`formatItemRange([1,2,3,5])` → `"1–3, 5"`

## 4. Validator — `validate(draft, course)` → `[{level:'error'|'warn', code, msg}]`

ข้อความเป็นภาษาไทย บอกตัวเลขและสิ่งที่ต้องแก้

| code | ระดับ | เงื่อนไข | ตัวอย่างข้อความ |
|---|---|---|---|
| `RANGE_SYNTAX` | error | parse เลขข้อไม่ได้ | "แถวที่ 3 ช่องปรนัย: อ่าน '1-' ไม่ได้" |
| `OBJ_MISSING` | error | ข้อปรนัย 1..N ที่ไม่อยู่ในแถวใด | "ปรนัยข้อ 7, 12 ยังไม่ได้ใส่ในตาราง" |
| `OBJ_DUP` | error | ข้อซ้ำหลายแถว | "ปรนัยข้อ 5 อยู่ 2 แถว (แถว 1, 3)" |
| `OBJ_OUT` | error | เลขข้อนอก 1..N | "ปรนัยมี 20 ข้อ แต่ใส่ข้อ 22" |
| `SUBJ_MISSING` / `SUBJ_DUP` / `SUBJ_OUT` | error | เหมือนด้านบน ช่วง N+1..N+M | |
| `SUBJ_POINTS` | error | ความยาว `points` ≠ count หรือมีค่า ≤0 | |
| `TOTAL_VS_COURSE` | error | คะแนนรวม ≠ `mid_exam`/`fin_exam` (ถ้าค่านั้นมี) | "คะแนนรวม 25 แต่คะแนนสอบกลางภาควิชานี้ = 15" |
| `RATIO` | warn | ร้อยละปรนัย ≠ 70 (คลาดเกิน `RATIO_TOLERANCE`) | "ปรนัยร้อยละ 60 / อัตนัย 40 (เกณฑ์ 70 : 30)" |
| `ROW_INCOMPLETE` | error | แถวไม่มีหน่วย/ตัวชี้วัด/Bloom หรือไม่มีเลขข้อเลย | |
| `INDICATOR_UNUSED` | warn | ตัวชี้วัดของหน่วยในช่วงสอบ (เฉพาะวิชาที่ผูกหน่วยแล้ว) ไม่มีข้อสอบ | |
| `NO_COURSE_TOTAL` | warn | รายวิชาไม่มีค่าคะแนนสอบ → ตรวจคะแนนรวมไม่ได้ | |

- ปุ่มดาวน์โหลดกดได้เสมอ แต่ถ้ามี error ให้ขึ้นยืนยัน "ยังมี N จุดต้องแก้ ดาวน์โหลดต่อหรือไม่" (ครูอาจต้องการร่าง)
- ตรวจแบบสดทุกครั้งที่แก้ (debounce ~300ms)

## 5. UI (หน้าเดียว, ใช้ได้บนมือถือ)

1. **เลือกวิชา:** ค้นหาด้วยรหัส/ชื่อ (เฉพาะ `is_scheduled_term2`), เลือก กลางภาค/ปลายภาค → เติมหัวเอกสารอัตโนมัติ, ช่องชื่อครู
2. **รูปแบบแบบทดสอบ:** ปรนัย (จำนวนข้อ, คะแนน/ข้อ) · อัตนัย (จำนวนข้อ → ช่องคะแนนรายข้อตามจำนวน) → แสดง รวม/ร้อยละ แบบสด เทียบคะแนนสอบของวิชา
3. **ตาราง:** ปุ่ม "+ เพิ่มแถว"; แต่ละแถว: หน่วย (dropdown ช่วงสอบ) → ตัวชี้วัด (dropdown + "พิมพ์เอง") → Bloom (1–6) → ปรนัยข้อที่ → อัตนัยข้อที่ → [จำนวน/คะแนน คำนวณเอง]; ลบ/ย้ายแถวได้
   - แถบสด: "ยังไม่ได้ใส่: ปรนัย 7, 12 · อัตนัย 22"
4. **แผงตรวจ** error/warn (คลิกแล้วเลื่อนไปแถวนั้น)
5. **ปุ่ม:** ดาวน์โหลด วผ.29 (.docx) · ส่งออก/นำเข้าไฟล์งาน · ล้างฟอร์ม (ยืนยันก่อน)
6. บันทึกอัตโนมัติลง localStorage (try/catch — ใช้ไม่ได้ก็ทำงานต่อ)

## 6. Export — ต้องเหมือนต้นฉบับ

### 6.1 สร้างแม่แบบ `templates/wp29_template.docx`
- คัดจากต้นฉบับเฉพาะส่วน วผ.29 (ตราโรงเรียน → หมายเหตุ Bloom) **คงรูปแบบ ฟอนต์ ขนาด เส้นตาราง ตรา และตำแหน่งเดิม**
- ใส่ placeholder `{{...}}` ในจุดเติมคำ (แต่ละ placeholder ต้องอยู่ใน `<w:r>` เดียว — ตรวจด้วยการเปิด document.xml)
- ตารางหลัก: เหลือ **แถวต้นแบบ 1 แถว** (สำเนาแถว "1") + แถว "รวม"; ตัดข้อมูลตัวอย่าง (ค 3.1 ม.6/1 ฯลฯ) ออก
- ข้อความแนะนำสีแดง "(คิดสัดส่วน... ต้องออกข้อสอบสัดส่วนคะแนนร้อยละ 70)" → แทนด้วยค่าร้อยละที่คำนวณได้ (สีดำ) — **นอกจากนี้ไม่เปลี่ยนข้อความใดของต้นฉบับ**
- เติมตัวเลข "1.3" ที่ต้นฉบับวางผิดบรรทัด: คงไว้ตามต้นฉบับ (ไม่แก้ในรอบนี้)
